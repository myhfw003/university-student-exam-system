# ADR-012：防作弊定位为可审计与可威慑，非绝对防护

**状态**：已接受　**日期**：2026-11-12

## 背景

产品需求里有「防作弊」。但只要考生手里有键盘、屏幕和网络，就不存在能「杜绝」作弊的技术手段：
远程桌面、虚拟机、多设备协同、二次拍照……任何声称能杜绝的方案都会给用户虚假的安全感，
并且把成本花在无法兑现的地方。

## 候选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| 承诺杜绝作弊（强客户端、深度检测） | 宣传好看 | 做不到；成本高；体验差；仍有绕过路径 |
| **可审计 + 可威慑** | 承诺可兑现 | 需要把「证据链」做扎实 |
| 不做任何防作弊 | 成本最低 | 无法满足考试纪律要求，也无法支撑事后认定 |

## 决策

定位为**可审计 + 可威慑**，对外表述统一为「可审计 + 可威慑」，**不写「杜绝作弊」**。

具体手段（每一条都留下可核查的痕迹）：

- 切屏 / 失焦事件：客户端上报，服务端计数，次数超限触发处置（ADR-011 的计时同样由服务端掌握）。
- 水印与全屏要求：屏幕上带身份水印，截屏外泄可溯源。
- 心跳与断线计数：断网超限按断网超时代交。
- 监考处置：警告 / 备注 / 强制交卷，全部进审计日志（`audit.audit_log`，追加式）。

## 代价与后果

- 手段有限，不可能挡住所有作弊形态；宣传口径必须与能力一致。
- 收益：每一次异常都有记录，事后可以认定、可以申诉、可以追责——
  这比一个做不到的承诺有用得多。
- 所有处置动作可追溯，本身也构成对考生的保护（争议时可回看记录）。
