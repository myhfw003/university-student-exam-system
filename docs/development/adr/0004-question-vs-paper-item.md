# ADR-004：题目与卷面题位分离建模

**状态**：已接受　**日期**：2026-11-12

## 背景

一道题可以出现在多张试卷里；同一道题在 A 卷里值 2 分、在 B 卷里值 5 分；
同一道题在 A 卷里排第 3、在 B 卷里排第 20。如果把题目和它在卷里的位置揉成一张表，
「这道题被改过」就会牵连到所有引用它的试卷。

## 候选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| 单表：题目即卷面题位 | 少一张表 | 一题多卷无法表达；改题目会改到所有卷 |
| 题库表 + 卷面题位表 | 题目与位置解耦 | 多一次关联查询 |
| 全 JSON 存卷面 | 读快 | 无法按题位查询、无法统计逐题正确率 |

## 决策

两张表：

- `catalog.question` —— 题目本体：题干、选项、题型、解析、标签、附件。题目有独立的
  发布 / 停用 / 恢复状态。
- `authoring.paper_item` —— 卷面题位：指向哪道题、分值多少、第几题、变式键（用于打乱选项顺序）。

统计口径（逐题正确率、掌握度）落在题位上：同一道题在不同卷里的分值不同，
按题位统计才对得上「这道题难不难」。

## 代价与后果

- 组卷、预览、判分都要多一次题位到题目的关联（已用索引覆盖 `(paper_id, order)` 与
  `question_id`）。
- 收益：题目可以复用于多张试卷与多个练习；题目的修订不会悄悄改动已发布的卷面
  （卷面绑的是快照，见 ADR-005）。
