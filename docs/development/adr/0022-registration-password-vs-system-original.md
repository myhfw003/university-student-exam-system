# ADR-022：注册时给的密码就是该账号的登录密码

**状态**：已接受　**日期**：2026-11-25

## 背景

ADR-021 定了「重置密码统一置为系统设定的原始密码」，并在补充一节里把
「初始密码只有一个来源」当成结论写死了。2026-11-25 产品澄清后，这个结论
只对**重置**成立，对**注册**不成立：

> 注册时填写的密码，是初始密码的概念，但是作为密码记录到数据库中……
>
> 注册时的所谓「初始密码」，就是注册密码，初始密码只是一个说词，
> 这个密码就是用户的登录密码。

拆开就是三句话：

1. 注册时给的密码以散列记进**该账号自己的密码字段**；
2. **「初始密码」只是叫法**，不是另一类凭据、也不是另设的一个字段——
   它就是这个账号的**登录密码**；
3. **重置密码不回退到它**，重置一律回系统设定的原始密码。

这条澄清还暴露了一个真缺陷：名单 CSV 的「初始密码」列**被后端静默丢弃**。
后端的列名词表里只有「密码」，没有「初始密码」，而管理端界面提示教师填的是
「初始密码」——教师给每个学生设的密码整列没进库，账号全部落到系统设定的
原始密码上，**没有任何提示**。前端 mock 的解析器认「初始密码」，所以前端测试全绿。

## 候选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| 名单里的密码只作提示、不入库 | 不用存初始密码 | 教师逐个手工设密码，工作量大且容易漏；与澄清冲突 |
| 初始密码另设一个字段存着，重置时回填 | 重置能回到用户自己那一个 | 与澄清第 3 条冲突；等于系统替每个用户长期保存一份弱密码散列 |
| **注册时给的密码按账号存进密码字段，就是该账号的登录密码；重置回系统原始密码** | 与澄清逐句对上；名单里填了就真的生效；重置语义仍然单一 | 需要把「注册时给的」与「系统统一设置的」两种来源在界面与文档上讲清楚 |

## 决策

**注册时给的密码就是该账号的登录密码；「初始密码」只是叫法。重置密码一律回系统设定的原始密码。**

- **后端认「初始密码」这一列**：名单列名词表与前端 `roster.ts` 逐字一致
  （含「初始密码」「帐号」「工号」「用户名」「院系」「班级」「邮件」「身份」等别名），
  两边由 `scripts/check-roster-columns.py` 在 CI 里比对，漂了就红。
  列的匹配算法也统一：先找**完全相等**的表头，再找**包含**关键词的表头，
  一列只被认领一次（`username` 不会被 `name` 抢走）。
- **注册时给的密码记进该账号自己的密码字段**：`POST /users/import` 建号时用
  `PasswordPolicy` 校验后取 PBKDF2 哈希，写进这个账号自己的密码字段。
- **不因它来自名单而强制改密**：教师按学生逐个定的那一个密码不是全系统共用的
  值，学生就用它登录，不置「必须改密」。
- **只有落回系统设定的原始密码时才置「必须改密」**（名单里那一列留空）：
  那是全系统共用的一个值，用户登录后必须改掉。
- **重置语义不变**：`POST /users/{id}/reset-password` 一律置为系统设定的原始密码，
  **不会**回到该用户注册时自己定的那个。没配原始密码时仍然 422 / 29005。
- **名单里没填这一列时**才回落到系统设定的原始密码（沿用 ADR-021 的路径与代价）。
- **前端与文档同步**：管理端「名单 CSV 列定义」与导入结果说明改成上面这套口径
  （说「该账号的登录密码」，「初始密码」只作为 CSV 的列名出现）；
  前后端的密码规则常量（最短 / 最长长度）由同一个 CI 脚本比对。

## 代价与后果

- **两种来源仍要分清**：注册时教师逐个给定的密码，与系统设定的原始密码（全系统
  一个值）。差别在**是否强制改密**，不在「是不是登录密码」——两者都是登录密码。
- **用系统原始密码的账号仍共用同一份哈希与盐**（ADR-021 的代价不变）：
  重置的、新建的、名单里没给初始密码的，都落在这一类；名单里给了密码的账号
  各有各的哈希。
- **导入后账号的密码不再统一**：教师给了一列初始密码，这批账号的密码各不相同，
  告知与分发的工作回到教师手上（本来就是这个意思）。
- **旧的名单文件不受影响**：没填「初始密码」列的，行为与之前完全一致。

## 与既有 ADR 的关系

- **ADR-021 的主决策不变**（重置回系统设定的原始密码、响应里不带密码）。
- **ADR-021 补充一节「初始密码只有这一个来源」的结论被本 ADR 取代**：
  重置只有系统原始密码一个来源；注册时给的那个就是该账号的登录密码。
