# 教师手册（知行测评）

面向任课教师、阅卷教师与考务人员。系统里的每一步都会留痕（谁在什么时候改了什么），
出问题时按《审计与追溯》查。

## 1. 账号与角色

| 角色 | 能做什么 |
|---|---|
| 系统管理员 | 全部功能：用户、角色、标签、题库、试卷、场次、审计、运维 |
| 教师 | 题库、试卷、组卷、场次、名单、阅卷、成绩发布、统计 |
| 阅卷教师 | 阅卷任务队列、评分、查看自己批过的卷 |
| 学生 | 考试与练习 |

- 角色与权限点是固定的 35 个，**权限不能自定义到人**，只能给角色。
- 学生名单按**组织标签**圈定（§3），而不是逐个勾人。
- 名单导入的 CSV 里可以给每个学生定一个密码（「初始密码」列）：
  它就是这个账号的**登录密码**，学生用它登录即可。
  那一列留空时，账号用**系统设定的原始密码**（全系统共用一个，
  那种账号学生首次登录必须改密）。
- 新建用户时不给密码，用的是「系统设置」里配好的**系统原始密码**；
  用户首次登录必须改密。

## 2. 题库与题目

### 2.1 建题

1. 「题库」→ 新建题库（按学科或用途分库）。
2. 「题目」→ 新建题目。**新建一律是草稿**，草稿可改可删。
3. 题目要素：题干、题型、选项、正确答案、解析、难度、知识点、能力维度标签。
4. 发布后题目进入可用池；停用（不是删除）可随时恢复。

### 2.2 批量导入（Excel / CSV）

1. 「导入」→ **先下载导入模板**：模板里有表头、示例行与「填写说明」，
   页面上也直接列出每一列怎么填、哪些必填。照着填就不会对不上列。
2. 「导入」→ 上传文件（`.xlsx` 或 `.csv`）。
3. 系统给出**列映射建议**，检查表头对应关系，可手工调整后重新解析。
4. 看**逐行结果**：每行单独给结论（成功 / 失败 + 原因）。
   **单行出错只跳过该行**，其他行照常通过。
5. 「采纳」后落为**草稿题目**，仍需走发布流程。

> 常见问题：答案列写「对/错」「√/×」无法识别，题型列写了「单选（只有一个）」无法识别——
> 请按模板的列名与取值填写。

### 2.3 AI 生成试题

1. 「题库工作台」→「内容生产」→「AI 生成」。
2. 选**供应商**（MiniMax 等）与**模型**：同一供应商的不同模型质量与速度不同，
   随时可切；模型清单由服务端配置决定。
3. 填出题要求：题型、数量、难度、知识点，再写一句文字要求
   （如「围绕 TCP 三次握手与四次挥手出单选题」）。
4. 点「生成候选题」。模型产出的题**按与文件导入相同的规则**校验：
   - 通过的题直接进入**候选题队列**（草稿），在「候选题」标签页复核后发布；
   - 通不过的题**不落库**，并逐条说明哪里不合法（例如「多选题至少两个正确答案」）。
5. 服务端没配 API Key 时，界面上会直接提示「服务端未配置」，请联系管理员。

> AI 生成的题**一律是草稿**：它可以帮你起草，但不能替你决定「这道题该进题库」。
> 审核时重点看：题干是否泄题、干扰选项是否似是而非、答案是否唯一。

### 2.4 附件

题目附件（图片、文档）先上传到对象存储，再挂到题目上。
**附件不会直接暴露存储地址**，取图时换一张短期签名 URL。

## 3. 标签与组织

- 标签按维度分组：**知识点、能力维度、难度、组织**等。
- 组织维度用树表达（学院 → 专业 → 班级），可展开到任意层级。
- 名单与场次按组织标签圈定：给一个班级打标签，场次就能带上这个班的全部学生。
- 标签被引用时不能删；删除是软删除，历史记录不受影响。

## 4. 组卷与试卷

### 4.1 建卷

「试卷」→ 新建（草稿）→ 选择是**考试卷**还是**练习卷**（两者的规则不同：考试卷有切屏上限、
心跳、提前入场；练习卷有次数、即时反馈）。

### 4.2 组卷方案（蓝图）

1. 给试卷配**组卷方案**：按题型 / 知识点 / 能力 / 难度各要多少题、总分多少。
2. 「执行抽题」：同一方案 + 同一题库 → **同一份卷子**（可复现）。
3. 题池不足时会**明确报错并列出缺口**（缺哪个维度、缺几道、可用候选有多少），
   不会给你一份悄悄缩水的卷子。去补题库或改方案。
4. 「差异」按钮对比方案与当前卷面。

### 4.3 题位

题位 = 这道题在卷子里的位置：分值、第几题、选项顺序变式。
「整体替换题位」一次改完；也支持追加、调整单题位、移除。

### 4.4 发布

1. 「校验」：检查总分、题量、答案完整性等。**校验不改变状态**。
2. 「发布」：有警告项时必须填写**覆盖理由**（会进审计日志）。
3. 发布时生成**不可变试卷快照**——场次绑的是快照。之后再改卷子不影响已发布的场次。

## 5. 考试场次

### 5.1 建场次

1. 「场次」→ 新建：选试卷、开放时间（`open_at` / `close_at`）、时长、监考规则
   （切屏上限、心跳间隔与超时、最大断连次数、允许提前入场分钟数）。
2. 「设置名单」：按组织标签圈人。已发布的场次改名单会**立即重新物化**考生名单。
3. 「发布场次」：试卷必须已发布且有快照。

### 5.2 考试中

- 监考大屏实时显示每名考生的在线状态、切屏次数、断线次数与作答进度（每 2 秒刷新一批）。
- 处置动作：**警告 / 备注 / 强制交卷**。每次处置都进审计日志并显示在考生的时间线上。
- 场次可「关闭」（正常结束）或「取消」（异常中止）：
  - 关闭后考生不能再作答，已提交的保留。
  - 取消后已开始作答的会话拒绝继续作答，已提交的保留。

### 5.3 成绩发布

- 「场次成绩」里可以**全部发布**或**只发布客观题**（主观题等阅卷完成再发）。
- 未发布的成绩学生看不到。
- 成绩发布后可查看成绩分析：平均分、极差、及格率、优秀率、分数段分布、逐题型正确率。

## 6. 阅卷

1. 「阅卷任务」是队列：待领取 / 阅卷中 / 已阅完 / 我的。
2. **先到先得**：领取后别人就领不走了；已被领走再领会失败。
3. 卷宗详情里有：考生作答原文、参考答案、系统初判的要点命中。
4. 评分：0 到满分，**0.5 为步进**。每次评分都**追加一条改分流水**（不覆盖历史）。
5. 「批量采纳初判建议」：只对待领取的任务生效，逐条给出采纳与跳过的结果。
6. 「上一份 / 下一份」连续阅卷。

## 7. 统计与画像

- **场次成绩分析**：平均分、极差、及格率、优秀率、分数段分布、逐题型正确率。
- **逐题正确率**：一道题在全部场次里的正确率、掌握度、讲评建议与逐场次分布。
- **能力画像**：按知识点与能力维度汇总；样本不足的不参与排序。

## 8. 审计与追溯

- 「审计日志」可按动作、目标、操作人与时间范围过滤。
- 重点动作都有留痕：发布试卷、发布场次、设置名单、监考处置、评分改分、
  发布成绩、导入题目、用户与角色变更、重置密码、禁用账号。
- 追加式表（答案修订流水、审计日志）在数据库层就没有 `UPDATE` / `DELETE` 权限——
  **写错了只能追加更正记录，不能改历史**。

## 9. 常见问题

| 问题 | 怎么办 |
|---|---|
| 抽题报「题池不足」 | 按提示补题库或改方案；系统不会降级出卷。 |
| 发布试卷要填覆盖理由 | 警告项必须确认；理由会进审计日志，便于事后解释。 |
| 改了卷子，已发布的场次没变 | 这是对的：场次绑的是**快照**，考试卷面以开考那一刻为准。 |
| 名单改了，但人数不对 | 检查组织标签的覆盖范围；标签变更后需要重新设置名单。 |
| 阅卷任务被领走了 | 队列先到先得；可以「指派」给指定阅卷人。 |
| 学生说成绩不对 | 「我的成绩」里能看到改分流水；按学校申诉流程提交。 |
| 误删了标签 | 标签是软删除，可以从历史里找回。 |
