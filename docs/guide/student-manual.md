# 学生手册（知行测评）

面向参加考试与练习的学生。遇到问题先看《常见问题》，再联系监考教师或班主任。

## 1. 登录

1. 打开学校给的考试网址，用学号或工号与**初始密码**登录
   （初始密码由班主任或任课教师发给你）。
2. 首次登录会要求修改密码：密码至少 8 位，建议字母 + 数字组合。
3. 登录状态会保持一段时间；长时间不操作需要重新登录，重新登录后**未交卷的考试不会丢失**
   （答案在服务端，见 §5.3）。

> 忘记密码找班主任重置。重置之后，之前登录的设备会被强制退出。

## 2. 工作台

登录后进入工作台，一眼能看到：

- **进行中的考试**：已发布且在你名单里的场次，点进去直接开始作答。
- **推荐练习**：按你的错题与能力画像推荐。
- **最近成绩**与**成绩趋势**：上学期比这学期进步了多少。
- **错题数量**：点进去是错题本（§6）。

## 3. 考试

### 3.1 进入考试

1. 在工作台点「进入考试」，或从「考试」列表进入。
2. 系统会给你一个**作答会话**（同一次考试重复点进来不会重复创建）。
3. 卷面在**开考那一刻已经固定**：题目、选项顺序、分值都不会再变，即使老师随后改了卷子。

### 3.2 答题

- 单选 / 判断：点选项即可。
- 填空：输入文字。
- 综合题：按步骤作答（每一步单独一块）。
- 答题区显示**剩余时间**（以服务端时钟为准，你的电脑时间不准也不影响判定）。

### 3.3 答案什么时候保存

答案**自动保存**，不需要你点保存：

- 每隔几秒自动保存一批（你也可以随时点「保存」手动触发）。
- 题目上出现「已保存」标记即表示服务端已收到。
- 网络卡顿时会提示「正在重试」，请不要关闭页面。

### 3.4 切屏、水印与全屏

考试期间页面会有**带你身份的水印**，并可能要求全屏显示。这些是纪律要求：

- **离开考试页面（切屏、切换窗口、锁屏）会被记录**，次数累计。
- 切屏次数超过上限（默认 3 次）会**强制交卷**，未作答的题目按未作答计分。
- 监考教师能看到你的切屏次数与断线次数，可以随时警告或强制交卷。

> 正常的短暂切屏（接个电话、瞄一眼别的窗口）也会被记录。请尽量保持在考试页面。

### 3.5 交卷

- 倒计时归零，系统**自动交卷**（交卷原因记为「超时」）。
- 也可以提前手动交卷，需要二次确认。
- 交卷后不能修改答案。重复点交卷不会重复提交。

### 3.6 成绩与解析

- 客观题在交卷后立刻判分。
- 主观题进入阅卷队列，阅卷完成后在「我的成绩」里看到。
- 成绩报告里可以看**逐题明细**：你的作答、正确答案与解析。
- 正确答案与解析的公布时机由老师决定（有时考完先只出分数，解析等讲评时再给）。

### 3.7 成绩有异议

在「我的成绩」里可以看到**改分流水**：这个成绩被改过几次、谁改的、改成多少。
如果对结果有异议，按学校流程提交申诉，阅卷教师会依据流水与作答记录复核。

## 4. 练习

练习不限时，规则由老师设置（次数、是否计分、是否即时给反馈）。

1. 工作台「推荐练习」或「练习中心」进入。
2. 点「开始练习」，系统生成一份练习会话（题量与总分按老师的规则）。
3. 做完点「提交练习」，立刻看到得分与逐题解析（若老师开了即时反馈）。
4. 练习次数用完会提示；部分练习允许重做。

## 5. 网络与断线

### 5.1 断网了怎么办

- 页面会提示「网络异常，正在重连」，**不要关闭页面**。
- 断网期间你的操作会进入本地队列，网络恢复后自动补传。
- 服务端记录你的断线次数；超过上限会按「断网超时」自动交卷。

### 5.2 刷新 / 换了设备

- 刷新页面：作答会话与已保存的答案都在服务端，回来继续答。
- 换设备：用同一账号登录，答过的题会显示出来（未保存的最后几秒可能丢失，所以要等「已保存」）。

### 5.3 你的时间不准

考试倒计时以服务端时间为准。如果你的电脑时钟不对，界面里的倒计时可能看着不准，
但**判定不受影响**。仍然建议考试前把系统时间调准。

## 6. 错题本

- 错题本自动收录做错或标记有疑问的题，可按标签、题型、时间过滤。
- **单题重做**：把这道题做成一份只有一道题的练习并直接开好会话。
- **标记已掌握**：这道题不再留在错题本里（之后做错还会回来）。

## 7. 成绩与能力画像

- **我的成绩**：所有场次与练习的成绩列表。
- **能力画像**：按知识点、能力维度给出你的掌握情况；样本不足的部分不参与排序
  （刚考完一两场时看到画像不完整是正常的）。

## 8. 常见问题

| 问题 | 怎么办 |
|---|---|
| 交卷后还能改答案吗 | 不能。交卷即封卷。 |
| 切屏会不会影响成绩 | 切屏本身不扣分，但超限会**强制交卷**，未作答的题按未作答计。 |
| 忘记密码 | 找班主任重置；重置会踢掉已登录设备。 |
| 考试中途刷新了 | 不会丢答案：答案在服务端，回来接着答（最后几秒未保存的除外）。 |
| 成绩显示 0 分但我作答了 | 可能是主观题还没阅完；阅卷完成后会更新，并留下改分流水。 |
| 我不是这个名单里的人 | 场次名单由老师按组织标签生成，找老师核对。 |
| 练习还能再做几次 | 练习详情页会显示「自己还能做几次」。 |

## 9. 联系方式

- 考试纪律、名单、申诉：班主任或任课教师。
- 系统故障（页面打不开、一直转圈）：先截图与记时间，报给技术支持。
